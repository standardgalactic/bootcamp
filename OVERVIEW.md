# Bootcamp Project Overview

## Repository purpose

This repository documents practical coursework and projects completed across ten bootcamp weeks. It is organized as a progression from fundamentals to full-stack development.

## Top-level structure

- `week-01` to `week-10` — weekly exercises and projects
- `student_presentations` — slide decks and sample files used for presentations
- `README.md` — primary repository entry point
- `morze.py` — standalone Morse conversion example script

## Weekly focus areas

- **Week 01:** developer workflow basics, command line, Git, HTML/CSS
- **Week 02:** layout, semantic HTML, advanced CSS, forms
- **Week 03:** Python problem-solving and algorithm exercises
- **Week 04:** file I/O, recursion, graphics/fractal tasks
- **Week 05:** testing mindset, exceptions, CLI/GUI todo apps
- **Week 06:** OOP fundamentals and class-based project work
- **Week 07:** JavaScript fundamentals, arrays/objects, DOM, gallery project
- **Week 08:** TDD exercises, async programming, frontend apps
- **Week 09:** full-stack todo app with API and database
- **Week 10:** JavaScript pattern exercises and project continuation

## Representative project examples

- Image gallery (`week-07/gallery-project`)
- Frontend todo app (`week-08/4-access-backend/todo-project`)
- Backend todo API/database project (`week-09/todo_app`)
- OOP game/project work (`week-06/tkwanderer`)

## Notes

- The repository contains learning artifacts from multiple technologies (Python, JavaScript/Node.js, HTML/CSS, SQL).
- Some files and links reflect original bootcamp context and archived references.
